About

qb-td consolidates the logistics of a tournament by allowing tournament directors to set up rooms, packets, a roster and a schedule before the start of a tournament. Each moderator is given a room link that automatically chooses team and packet for the round number the tournament is on. When moderators are done reading a game in MODAQ, they click on an export button that is sent to the TD and automatically processed. Players are given a page which contains schedule and detailed stats that are updated as games are exported.

Importantly, qb-td is compatible with all the standard procedures for holding MODAQ tournaments. TDs can export to yellowfruit, directly to the html stat reports, and download QBJ files to send to set editors.
