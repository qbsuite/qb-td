Pool grids on the public stats page

The New layout lists each pool’s standings, but not who has played whom. Below are three ways to add a square grid for each pool. The page is ACF Fall @ UIUC with made-up results: rounds 1 to 4 are in and rounds 5 to 7 are still to come, so the grids show a pool partway through.

A1. A grid beside each table

Every pool keeps its table and gains a grid of scores to its right. Short team names label both sides, and the full name shows on hover. On a phone the grid sits under the table.

The names are shortened (Ill A, NU B) so that the grid fits beside an eight-team table.

A2. A grid under each table

The grid sits under the table with full team names down the side and along the top, where they are set at an angle.

Each pool takes more height, so the three pools make a longer page.

C. A Table or Grid switch

Each pool has a switch. The grid replaces the table, with full names down the side, short names across, scores in every square and the record at the end.

The table and the grid are never on screen together. The first pool is shown as Grid and the others as Table.
