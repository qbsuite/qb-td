How it saves

  • The Worker hands back the stored upload, the hub rewrites it, and it goes back up the room’s own upload route, the same path Edit in MODAQ uses. The newest upload counts, so stats, buzzpoints, exports and the public page all follow.
  • Players move only within their own team. A whole-game swap is renameMatch (engine/qbj.js) with a two-way map for one team: buzzes, match_players, tossups_heard and lineups all trade. Changes in All buzzes rename only those buzzes and recounts answer_counts; tossups heard stay as they were.
  • For a reader upload, the MODAQ half gets the same change on its buzz markers, so Edit in MODAQ opens the fixed game.
  • Team scores never change.
