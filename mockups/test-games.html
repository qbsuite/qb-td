Test games before Start

Today a room link shows “Tournament hasn’t started” until the TD presses Start tournament, and Start begins the 48-hour clock. A TD therefore cannot check that packets, rosters and MODAQ settings load correctly without spending the clock. Below are three ways to allow it.

A. A test link for the TD

Each room in Setup gets a Test link. It opens that room exactly as it will look on the day, with the real packets, teams and settings, on the TD’s computer only. Nothing from a test game is sent anywhere.

Moderators’ own links stay closed, so they cannot rehearse, and the upload step is not exercised.

B. Open the rooms for testing

The TD can open every room link before Start without starting the clock. Moderators can read test games on their own laptops and upload them, and the TD sees them arrive. Test games are deleted when the tournament starts.

Anyone holding a room link can read the real packets while testing is open.

C. A practice game on the room page

Before Start, every room link offers a practice game with the tournament’s real teams and MODAQ settings but a sample packet. Moderators can try it whenever they like and the TD does nothing.

The real packets are never loaded, so this does not show that they read correctly.

A green outline marks what each proposal adds. It is not part of the design.
